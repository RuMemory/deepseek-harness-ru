# Глоссарий перевода DSH (стиль: максимально русский)

## Правила
- Переводим только ЗНАЧЕНИЯ. Ключи ("saveAs": ...) не трогаем.
- Плейсхолдеры {name}, {count}, {percent} и т.п. сохраняем точно, включая фигурные скобки.
- Форматирование: \n, markdown-ссылки, HTML-теги, эмодзи — сохраняем как есть.
- Многоточие — символ … (как в оригинале).
- Тон: деловой русский, «вы» не нужно (интерфейс безличный). Императивы для кнопок: «Сохранить», «Удалить».
- Не переводим: имена собственные (DeepSeek, DSH, MCP, API, JSON, YAML, URL, HTML, PDF, Git, pnpm, npm), названия моделей (kimi-k3, deepseek-v4), имена пакетов, пути, команды.
